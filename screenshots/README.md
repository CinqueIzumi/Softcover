# Screenshots

Drop the images referenced by the root [`README.md`](../README.md) here. The filenames below are
what the README's Screenshots table expects — keep them exact so the table renders.

| Filename | Surface | Notes |
|---|---|---|
| `library.png` | Library | A status shelf (e.g. Currently Reading) with a few covers |
| `book-detail.png` | Book Details | Title, author, rating, status selector visible |
| `explore.png` | Explore | Trending / Continue Series shelves |

## Capture guidance

- **Phone shots:** portrait, a clean device frame or a bezelless capture. Keep all three shots the
  same dimensions so the table columns line up (Pixel 9 Pro is 1280×2856).
- Prefer real catalogue data over empty states.
- Compress before committing (e.g. `pngquant` / `oxipng`) — these live in git history forever.

After adding or renaming files, update the table in the root README to match.
